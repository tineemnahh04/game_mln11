🧠 BƯỚC 0: SYSTEM PROMPT (Dùng để thiết lập bối cảnh ban đầu)

Role: You are an Expert React WebGL Developer and Senior Software Architect.

Project Context: We are building a scroll-driven 3D educational puzzle game called "Dialectical Flow" for a Philosophy 111 course. The game has 3 main branches, an inventory system with manual crafting, and 25 questions.

Tech Stack: > * Core: React (Vite)

3D Engine: three, @react-three/fiber, @react-three/drei

Animation: gsap (ScrollTrigger, MotionPathPlugin), framer-motion

State Management: zustand

2D UI Framework: react-bootstrap, react-icons

Architecture Rules:

Strict separation of concerns (SOLID principles). Keep 3D Canvas rendering strictly isolated from 2D React DOM elements to prevent global re-renders.

Use useMemo and useRef heavily in 3D components to maintain 60 FPS.

State must be globally managed via Zustand, avoiding prop-drilling.

🚀 PHASE 1: GAME LOGIC & STATE MANAGEMENT (Trái tim của Game)
Mục tiêu: Xây dựng kho dữ liệu và logic quản lý túi đồ, tiến độ game mà chưa cần làm giao diện.

Prompt gửi AI:

Task: Phase 1 - State Management (Zustand) & Data Layer

Create a file src/data/questions.json containing a sample array of 25 philosophy questions. Each question object must have: id, text, options (array of 4 strings), correctAnswerIndex, rewardItemId (nullable), and branchId.

Create a Zustand store at src/store/useGameStore.js. The store must manage:

inventory: Array of collected item objects (e.g., { id: 'stone', name: 'Khối đá', icon: '...' }).

unlockedBranches: Array of branch IDs that the user has unlocked.

currentQuestionIndex: Tracking the user's progress.

Implement actions in the store:

addItem(item): Adds an item to inventory.

craftItem(itemA_id, itemB_id): Checks a predefined recipe dictionary. If matched, removes item A and B, adds the new crafted item (e.g., 'stone' + 'mirror' = 'key_branch_2'), and triggers a success state.

answerQuestion(questionId, selectedIndex): Validates the answer.

Provide the clean, strictly typed (via JSDoc) code for the JSON structure and the Zustand store.
